# Bellabeat-case-study

Bellabeat User Behaviour Analysis
Google Data Analytics Capstone Project
Overview
Analysis of FitBit fitness tracker data from 33 users to identify patterns in activity, sleep, and calorie burn, with actionable recommendations for Bellabeat's marketing strategy.
Tools Used

Python (Pandas, Matplotlib, Seaborn)
Tableau Public
Google Colab / Kaggle Notebooks

Key Findings

No users hit the recommended 10,000 steps or 8 hours of sleep
Saturday is the most active day, Sunday the least
Mid-week activity drops significantly Wednesday to Friday
58% of users fall in the moderate activity category

Recommendations

Smart bedtime reminders on Tuesday and Thursday nights
Mid-week motivation nudges on Wednesday afternoons
Personalised micro-goals for moderate activity users
Intensity tracking beyond just step counting
